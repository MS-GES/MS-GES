## 📋 Engineering Standards & Repository Guidelines

All repositories hosted under the MS Holdings GitHub organization follow established engineering standards maintained by the MS GES Technology Department:

1. **Branching Strategy:**
   - `main` / `production`: Protected production-ready branch. Direct pushes are disabled.
   - `staging` / `develop`: Integration testing and pre-production validation.
   - `feature/*`, `fix/*`, `chore/*`: Working branches created from active development branches.

2. **Pull Requests & Code Reviews:**
   - All contributions require peer review and approval from repository maintainers before merge.
   - Automated CI checks (unit tests, linting, security scans) must pass prior to merge.

3. **Security & Secrets Hygiene:**
   - Never commit sensitive keys, secrets, API tokens, or `.env` files into source control.
   - Use centralized environment variable management and repository secrets.
